# RoVibe has moved

RoVibe's installers and updates are now published in **[aaldersondev/rovibe-releases](https://github.com/aaldersondev/rovibe-releases)**.

This repository only keeps the release copies of RoVibe up to 0.14.4 look for, so that they update to a version that reads the new address. Its code was published under the MIT license up to 0.14.4; RoVibe is proprietary from 0.14.5 on.
